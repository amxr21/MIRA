Mission Brief

What is MIRA?

MIRA is an autonomous Mars rover platform built entirely on edge hardware — no LiDAR, no cloud compute, no NVIDIA Jetson. It runs a complete dual-branch AI perception pipeline on a Hailo-8L NPU, achieving real-time terrain detection and depth estimation at 15–20 FPS.

The system fuses data from five TOF sensors, an IMU, an LDR, and a camera to make four autonomous navigation decisions: FORWARD, SLOW, TURN, and STOP — with end-to-end latency under 500ms.

MIRA was presented at the Made in CCI Exhibition 2026 at the University of Sharjah, and the research paper is currently being prepared for submission to an international IEEE conference.

  • Platform Raspberry Pi 5 + Hailo-8L NPU
  • Vision Model YOLO26n-seg + DepthAnything V2
  • Training Data 19,757 AI4Mars Labels
  • Training Platform AWS SageMaker / NVIDIA A10G
  • Sensor Fusion BEVFusion-inspired (ICRA 2023)
  • Languages Python + C++
  • Power Budget Sub-18W · 3hr Autonomous Op.
  • Navigation Outputs FORWARD / SLOW / TURN / STOP
Intelligence System

Dual-Branch AI Pipeline

01
Vision Branch
YOLO26n-seg detects and classifies Mars terrain in real time — rocks, bedrock, sand, and slopes — with pixel-level segmentation at 15–20 FPS on the Hailo-8L NPU.

Fine-tuned on 19,757 Martian terrain labels from the AI4Mars dataset using AWS SageMaker on an NVIDIA A10G GPU.
YOLO Segmentation Hailo-8L AI4Mars
02
Depth Branch
DepthAnything V2 Small generates dense monocular depth maps from a single camera — no stereo, no LiDAR required. Provides continuous depth estimation across the full field of view.

Validated against 5× VL53L1X TOF sensors for physical distance confirmation at key obstacle positions.
DepthAnything V2 Monocular Depth TOF Validation
03
Sensor Fusion
A custom BEVFusion-inspired fusion layer (MIT CSAIL, ICRA 2023) merges vision and physical sensor branches into a unified spatial representation.

Fuses TOF, IMU, LDR, and ultrasonic telemetry to output four real-time navigation commands with full pipeline latency under 500ms.
BEVFusion IMU LDR Ultrasonic
Physical Platform

Hardware Stack

🧠
Hailo-8L NPU
Dedicated AI accelerator delivering 12× inference speedup over CPU-only. Runs YOLO and DepthAnything V2 simultaneously at 15–20 FPS.
💻
Raspberry Pi 5
Main compute platform running Python orchestration and C++ communication layers. Manages all sensor I/O and decision output.
📡
5× VL53L1X TOF Sensors
Time-of-flight sensors providing physical depth validation and obstacle proximity detection across five directional zones.
🎯
Arduino Mega
Handles low-level sensor reading, motor control, and serial communication with the Raspberry Pi at 30Hz update rate.
📷
Camera Module
Single camera input feeding both the YOLO segmentation branch and DepthAnything V2 — no stereo camera required.
⚡
IMU + LDR
IMU provides slope, pitch, roll, and yaw for terrain tilt detection. LDR enables light-aware confidence weighting in the fusion layer.
